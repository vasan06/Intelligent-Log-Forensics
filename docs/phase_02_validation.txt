Concept notes
- A migration is a versioned, repeatable database change. Raw SQL needs version control so every
  environment reaches the same schema in a known order.
- A parameterized query sends SQL separately from values. psycopg2 escapes and binds values, so
  attacker-controlled text cannot become executable SQL syntax.
