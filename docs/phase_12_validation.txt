Features and logic
- App image runs migration runner before one Gunicorn process with threaded request concurrency.
- One process is intentional because live generator state and SSE subscriptions are process-local.
- PostgreSQL, uploads, models, reports, and database state use named volumes.
- Successful uploads self-delete; retained failure artifacts are removed by the 24-hour cleanup policy.
