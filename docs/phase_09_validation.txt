Features and logic
- Server-Sent Events broker publishes committed risk events to per-client bounded queues.
- EventSource refreshes stat cards and prepends live incident-feed rows without manual refresh.
- Doughnut chart clicks retain the selected segment and dim other segments to 20% opacity.

Concept notes
- SSE is a long-lived HTTP response carrying server-to-browser events. It fits this dashboard because
  updates travel in one direction; WebSockets would add bidirectional protocol complexity not needed here.

Validation and cross-checking

- Bounded queues prevent unbounded slow-client memory use.
